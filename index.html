HaLOS APT Repository

Debian packages for the HaLOS operating system

Repository Setup

Add the HaLOS repository to your system:

curl -fsSL https://apt.halos.fi/halos-apt-key.asc | sudo gpg --dearmor -o /usr/share/keyrings/halos.gpg echo "deb [signed-by=/usr/share/keyrings/halos.gpg] https://apt.halos.fi main" | sudo tee -a /etc/apt/sources.list.d/halos.list sudo apt update

Replace <distribution> with your desired distribution (e.g., trixie-stable)
