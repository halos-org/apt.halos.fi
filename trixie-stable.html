halos-browser-trust v0.1.0-2 all

Make on-device browsers trust the system CA store So Chromium, Firefox and other NSS applications on a HaLOS desktop trust CAs installed via update-ca-certificates — notably the device's own auto-CA — with no manual per-user steps. . Chromium and other system-NSS apps: replaces libnss3's libnssckbi.so with a symlink to p11-kit-trust.so (re-asserted via a dpkg trigger so it survives libnss3 upgrades), exposing the system p11-kit trust store the way Fedora and Arch do by default but Debian omits. . Firefox bundles its own NSS and root store, so a Firefox enterprise policy at /etc/firefox/policies/policies.json installs the system CA file instead. . Pulled in by the halos-desktop metapackage, so it lands only on desktop variants.

sudo apt install halos-browser-trust
